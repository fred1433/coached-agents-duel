From a coach's note to the next match

After each series, the two coached agents receive a short note and turn it into one lesson. The self-reflective agent gets the same type of post-match information about its own duels, without a note, and writes its own. Memory holds five lessons, so from the second round each new lesson has to replace one or be discarded.

What a two-week pilot could detect

These 48 runs demonstrate the engine and memory loop. They do not estimate a coaching effect. The paired experiment below is the proposed next test.

The simulation estimates what a two-week pilot could detect under explicit assumptions. Each coach's agent is split into a coached branch and a self-reflective branch from the same saved state; after two weeks both are frozen and play the same evaluation matches. The benefit of coaching is the gap between the two, coach by coach, tested across coaches.

How much the benefit varies between coaches
Replay noise

The +5 and +10 point gains are assumed end-of-pilot effects. The simulation does not predict how much agents learn in two weeks. More matches make each agent's score more precise. More coaches show whether the benefit holds beyond one coach. When the gap varies a lot between coaches, extra matches stop helping and only more coaches do.

A non-significant result is reported as the range of benefits still compatible with the data. "Undetermined at this size" is a possible outcome.
